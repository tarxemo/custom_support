CDN Integration Demo

This page demonstrates how to integrate the Customer Support Widget into a non-React project using the UMD bundle and the init() function.

<script src="https://unpkg.com/react@18/umd/react.production.min.js"></script>
<script src="https://unpkg.com/react-dom@18/umd/react-dom.production.min.js"></script>
<script src="https://unpkg.com/@tarxemo/customer_support/dist/index.umd.js"></script>

<script>
    CustomerSupport.init({
        apiKey: 'YOUR_API_KEY',
        theme: { primaryColor: '#2563eb' }
    });
</script>

The widget should appear in the bottom-right corner of the screen.
